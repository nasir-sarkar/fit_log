## 🏋️ FitLog — Workout Library

**FitLog** is a dark, no-nonsense gym companion. Browse a library of lifts, open any workout for the full breakdown, lock it into today's plan or save it for later, and watch your minutes and calories add up on the My Plan page.

**Live Site:** https://statuesque-fudge-ec830d.netlify.app/


## ⚙️ Technologies Used
- Next.js (App Router, Server & Client Components)
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Context API (state management)
- React Toastify


## 🚀 Features
- **Workout Library** – Every lift from the API in a responsive 3-column grid with muscle-group tags, equipment, duration, calories and rating.
- **Dynamic Details Page** – `/workouts/[id]` with a key specs panel, step-by-step instructions and a large workout image.
- **Today's Plan & Saved** – Add a lift to today's plan (capped at five) or save it for later, with live Plan / Saved counters in the navbar.
- **My Plan Dashboard** – Live Exercises / Minutes / Calories summary, Today's Plan and Saved tabs, sort by Duration, Calories or Rating, Mark as Done and Remove actions.
- **Custom 404 Page** – A dedicated not-found page for any unknown or invalid route.
